# CI / CD Labs
Laboratorios de integracion continua y entrega continua.

## Laboratorio 2 - Branching y Pull Requests
Este laboratorio implementa una estrategia de trabajo basada en ramas de funcionalidad, Pull Requests y validación mediante integración continua.

La rama principal `main` representa la versión estable del proyecto, mientras que las nuevas funcionalidades se desarrollan en ramas independientes.
